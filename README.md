# Salary Prediction with Multiple Linear Regression

A beginner-friendly machine-learning project that predicts a salary estimate from multiple input features and presents it in a Streamlit web app.

## Features used

- Age
- Years of Experience
- Education Level
- Job Title

**Target:** `Salary`

`Gender` is kept out of the model inputs because it is a sensitive attribute and should not be used as a salary-setting signal. The dataset's currency is not specified, so the app displays the estimate in the dataset's units.

## Tech stack

- Python
- pandas
- scikit-learn
- Multiple Linear Regression
- Streamlit
- Git and GitHub

## Run locally (Windows PowerShell)

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python train_model.py
streamlit run app.py
```

If PowerShell blocks activation, use Command Prompt or run `.venv\Scripts\python.exe -m pip install -r requirements.txt`, then `.venv\Scripts\python.exe train_model.py` and `.venv\Scripts\streamlit.exe run app.py`.

## Data preparation and evaluation

The training script:
1. normalizes a few education-level spelling variants,
2. removes exact duplicate records,
3. drops rows with missing target salary,
4. imputes missing feature values inside the training pipeline,
5. one-hot encodes categorical features,
6. uses an 80/20 train-test split and reports MAE, RMSE and R²,
7. fits a final pipeline on all cleaned data and saves it for Streamlit.

The source data contains repeated records and some unusually low salary values. Review the data quality and evaluation metrics before relying on predictions. This is a learning project, not a professional compensation tool.

## Push to GitHub

Create an empty repository on GitHub, then run these commands from this project folder:

```powershell
git init
git add .
git commit -m "Build salary prediction model with Streamlit"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

Replace the remote URL with your own repository URL. Do not commit passwords, tokens, or API keys.

## Deploy on Streamlit Community Cloud

1. Push the project to GitHub.
2. Open https://share.streamlit.io/ and sign in.
3. Select **Create app**, then choose your repository, branch (`main`), and main file path (`app.py`).
4. Deploy.

The generated model and JSON files are included in the repository after you run `train_model.py`. If you change the dataset or training code, rerun training and commit the updated generated files.
